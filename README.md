# 📘 Data Structures and Algorithms

Welcome to my Data Structures and Algorithms Weekly Challenge.

This repository documents my commitment to improving problem-solving skills, algorithmic thinking, and software engineering fundamentals.
Every week, I implement:

- 1 Data Structure

- 2 Algorithms

All implementations are written in two languages:

- JavaScript/TypeScript using NestJS (to reinforce backend skills and architectural patterns)

- Java (to deepen my understanding of classical CS fundamentals and strong typing)

## 🎯 Goals

- Build long-term consistency in algorithmic practice

- Strengthen mastery of time and space complexity

- Improve code quality through clean, maintainable implementations

- Learn how different languages approach the same problem

- Prepare for technical interviews and high-level backend challenges

- Develop reusable modules and utilities in both ecosystems
